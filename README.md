# Portfolio Oloumidé Ridolaye ALAMOU

Portfolio professionnel de Développeur Web Full-Stack, conçu avec Next.js, Tailwind CSS et Framer Motion.

## 🚀 Stack Technique
- **Framework** : Next.js 16 (App Router)
- **Styling** : Tailwind CSS v4
- **Animations** : Framer Motion
- **Icônes** : Lucide React
- **Langage** : TypeScript

## 📁 Structure du projet
- `src/app/` : Routing et configuration globale (layout, page, globals.css)
- `src/components/ui/` : Composants UI réutilisables (Button, Badge)
- `src/sections/` : Sections de la page d'accueil (Hero, About, Skills, etc.)
- `src/data/` : Données centralisées (profile.ts) pour une mise à jour facile
- `src/lib/` : Utilitaires (fonctions helpers)
- `public/assets/` : Images, CV et ressources statiques
